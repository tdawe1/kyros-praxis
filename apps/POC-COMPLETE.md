#### 1. User Registration Flow ✅
```
User → POST /auth/register → Database → 201 Created + User Info
```
**Evidence**: 6 tests passing, manual verification complete

#### 2. Login Flow ✅
```
User → POST /auth/login → Validate → Generate JWT → 200 OK + Token
```
**Evidence**: 4 tests passing, tokens validated

#### 3. Protected Access Flow ✅
```
User → GET /auth/me + Bearer Token → Validate JWT → 200 OK + User Info
```

**Evidence**: 5 tests passing, token validation working

```
User → POST /crews/runs → Queue → Run CrewAI → Stream Events → Store Result
```
